# Economy & Shop

## Coin Rules
- Activity success (first try): +4 coins
- Activity success (retry): +2 coins
- 3-streak bonus: +6 coins
- Level end: +20 coins
- Stars bonus: 2 stars +10, 3 stars +20
- Daily complete: +60 coins
- Streak 3 days: +40 coins
- Streak 7 days: +120 coins
- Anti-farm: repeating the same level on the same day yields 50% coins after the first completion.
